01 // THE ENGINEERING CONJECTURE: FIRST-PRINCIPLES WORKFLOW DESIGN
Monolithic Prompts Fail: Why We Engineered 3-Axis Review and State-Aware RCA
Started with zero predefined workflow requirements—formulated the workflow suite from first principles before building Akashic
1. Why Code Review Must Be 3 Orthogonal Axes
A single-pass "review this PR" prompt conflates syntax, product intent, and runtime cost. We designed 3 isolated, parallel sub-agent axes so one axis can never mask another:
Orthogonal Axis Verification Target Failure Mode Caught
Axis 1: Standards Repo conventions + Fowler code-smell baseline Spec pass, Standards fail (works, breaks repo design)
Axis 2: Spec Compliance Diff vs. authoritative spec (missing items / scope creep) Standards pass, Spec fail (clean code, wrong feature)
Axis 3: Complexity Before/after time & space Big-O + caller/callee blast radius Standards & Spec pass, Complexity fail (O(n²) / IPC regression)
Non-Masking Invariant: Sub-agents run in parallel without shared context pollution and never re-rank or suppress findings across axes.
2. Why Autonomous RCA Is Impossible Without Curated Context
Stateless "crash log + code → LLM" prompting collapses at OEM Android scale. Root cause analysis is a state-aware elimination process that fails without three curated inputs:
RCA Requirement Why Stateless / Uncurated Context Fails
Symbolicated Call Topology Raw stack traces show the crash frame (often a framework/HAL callback), not unstripped symbols (addr2line/R8), upstream callers, or cross-repo blast radius.
Stateful Soak Deduplication One regression in monkey soak testing triggers 100s of identical BugReport dumps; without durable CrashSignature state, agents re-investigate duplicates in a loop.
Curated Guidance & Negative Knowledge Raw vector RAG blends deprecated 2023 wiki pages with 2025 specs and lacks Negative Knowledge (falsified hypotheses & reverted CLs)—repeating failed fixes.
The Curated Context Imperative: An LLM cannot guess which of 3 conflicting wiki pages is active or which workaround was reverted last week.
The Conjecture That Birthed Akashic: Defining 3-Axis Code Review and State-Aware RCA from scratch revealed that off-the-shelf MCPs and vector RAG cannot feed them. Before autonomous agents can review or debug OEM codebases, a deterministic substrate must provide AST blast radius, supersession-aware specs, and Negative Knowledge.
